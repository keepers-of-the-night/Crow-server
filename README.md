# Crow HTTP Server

Простой и производительный HTTP-сервер на C++ с использованием фреймворка **Crow**.  
Проект включает аутентификацию через **JWT**, логирование, отдачу статических файлов и интерактивную документацию **Swagger UI**.

---

## Основные возможности

- **Готовые REST API эндпоинты**: приветствие, сумма чисел, выдача JWT, защищённый ресурс.
- **Аутентификация через JWT** (токен живёт 30 минут).
- **Логирование** всех запросов в консоль и в файл `server.log`.
- **Отдача статических файлов** (HTML, CSS, JS, изображения) из папки, указанной в `config.json`.
- **Интерактивная документация** через Swagger UI (доступна по адресу `/docs`).
- **Единый формат ошибок** в JSON.
- **Валидация входных данных** (проверка типов, наличия полей).
- **Гибкая конфигурация** через `config.json`.

## Требования

- **Компилятор**: MinGW-w64 (GCC) или MSVC (Visual Studio)
- **CMake** 3.10+
- **Зависимости** (уже включены в проект):
  - Crow (header-only)
  - ASIO (standalone)
  - jwt-cpp (header-only)
  - OpenSSL (заголовки и библиотеки)

---

## Сборка (MinGW)

1. Убедись, что `g++` и `cmake` установлены.
2. В корневой папке проекта выполни:

```bash
mkdir build
cd build
cmake .. -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
make
```

3. После сборки исполняемый файл crow_server.exe появится в папке build/.

---

## Запуск

Скопируй папку files/ и файл config.json в ту же папку, где лежит crow_server.exe (или запускай из корня проекта). Затем выполни:

```bash
./crow_server.exe
```

Сервер запустится на порту, указанном в config.json (по умолчанию 18080).

---

## Конфигурация (config.json)

```json
{
  "port": 18080,
  "static_path": "files",
  "log_level": "info"
}
```

* port – порт для прослушивания.
* static_path – папка со статическими файлами (относительно рабочей директории).
* log_level – уровень логирования (пока не используется, но можно расширить).

## API Эндпоинты

| Метод | Путь | Описание | Требуется JWT |
|-------|------|----------|:-------------:|
| GET   | `/` | Список всех доступных эндпоинтов | ❌ |
| GET   | `/hello/<name>` | Приветствие с валидацией имени | ❌ |
| GET   | `/json` | Пример JSON-ответа | ❌ |
| POST  | `/add` | Сложение двух чисел (поля `a`, `b` в JSON) | ❌ |
| POST  | `/login` | Получение JWT-токена (поля `username`, `password`) | ❌ |
| GET   | `/protected` | Защищённый ресурс (доступ только с токеном) | ✅ |
| GET   | `/files/<path>` | Отдача статического файла из папки `static_path` | ❌ (кроме `/swagger`) |

---

## Авторизация (JWT)

1. Отправь POST-запрос на /login с телом:

```json
{
  "username": "admin",
  "password": "password"
}
```

2. Получи токен вида:

```json
{"token":"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."}
```

3. Вставь этот токен в заголовок Authorization: Bearer <токен> для доступа к /protected.  
#### Токен действителен 30 минут.

## Документация (Swagger UI)

После запуска сервера открой в браузере:

```text
http://localhost:18080/docs
```

## Примеры запросов (curl)

#### Получение токена:

```bash
curl -X POST -H "Content-Type: application/json" -d '{"username":"admin","password":"password"}' http://localhost:18080/login
```

#### Запрос к защищённому ресурсу:

```bash
curl -H "Authorization: Bearer <ваш_токен>" http://localhost:18080/protected
```
#### Сложение чисел:

```bash
curl -X POST -H "Content-Type: application/json" -d '{"a":10,"b":32}' http://localhost:18080/add
```

#### Получение статического файла:

```text
[curl -X POST -H "Content-Type: application/json" -d '{"a":10,"b":32}' http://localhost:18080/add](http://localhost:18080/files/swagger/index.html)
```

---

## Логирование

Все запросы логируются в консоль сервера и в файл server.log (создаётся в рабочей директории). Формат лога:

```text
[Thu Aug 13 12:34:56 2026] GET / -> 200 (1 ms)
```

---

## Особенности реализации

* Middleware для логирования и JWT-аутентификации.
* Единый формат ошибок:

```json
{"error": true, "message": "Описание ошибки"}
```

* Валидация входных данных (проверка JSON, наличие полей, допустимые символы в имени).
* Защита от path traversal в /files (запрещён ..).
* Автоматический поиск DLL OpenSSL (путь задаётся в main.cpp относительно исполняемого файла).
